# Arush Gupta Portfolio

A premium one-page portfolio website with a dark glassmorphism aesthetic.

## Open the site

Open `index.html` directly in a browser.

## Add your real images

Place your images here:

- `images/arush-avatar.png`
- `images/arush-portrait.jpg`
- `images/arush-editorial.jpg`

The layout already includes slots for both images. If the files are missing, the site shows styled placeholders instead.

## Optional local hero video

If you want to replace the remote background video with your own file, add:

- `assets/videos/hero.mp4`

Then update the `<source>` in `index.html` to point to `assets/videos/hero.mp4`.

## Files

- `index.html` — site structure
- `styles.css` — layout and glassmorphism styling
- `script.js` — reveal animations and smooth scrolling
